# Native compatibility

Studio updates do not disable native features by version. `rbx native-probe --pid PID` performs read-only structural checks and prints one verdict per operation. `--require-native` exits unsuccessfully if any operation is degraded. `rbx status` and `rbx dr` include the selected process's cached verdicts and reasons. A passing probe validates locators; it does not claim a runtime stress test passed.

A failed operation uses its available plugin path. Source verification remains available. Protected values without a lossless bridge path remain pending with a precise error. Optional voxel-history acceleration can be degraded while ordinary history recording and explicit Terrain rollback work.

Maintainers: `powershell -File tools/renium/tests/native-canary.ps1` downloads the current WindowsStudio64 deployment into a unique scratch directory, launches its scratch place without taking focus, probes it and writes a per-operation table. It stops only its own scratch window and leaves evidence. Use `-Studio PATH -Place FILE` to compare an installed build. The scheduled **Studio native canary** workflow runs on `self-hosted, Windows, X64` and fails for any degraded operation except the optional voxel-history acceleration.

When a probe fails, retain `probes.json` and the deployment manifest; compare executable code/RTTI and update the narrow locator in `src/studio/native/serializer`. Add a relocated-layout regression and rerun probes plus the affected operation on a scratch place, including reconnects. Never extend a build allowlist or relax allocator/ownership checks to make a probe pass. Windows CI does not verify macOS runtime behavior.

macOS uses the same verdict model. Its local-save locator follows function boundaries, the serializer call graph and libc++ ownership. Studio action probes look up the window's QAction without activating it. Viewport capture accepts both the engine and launcher bundle layouts and checks Screen Recording access without opening a permission prompt. Service deserialization, native attribute observation and package actions still lack macOS implementations or verified bindings. PID-scoped native input was removed before these probes were introduced; macOS input uses the Studio bridge. These gaps report degraded even when their bridge alternatives work. Voxel playback remains optional and requires its own verified binding; ordinary history and explicit Terrain restoration work without it.
