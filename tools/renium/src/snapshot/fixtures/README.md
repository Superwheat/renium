`import-unique-id-*.renium` are complete store files generated by
`import_place_file` on main `96c0e94e1c8588a394ae90ae355e893ecd6b1a06`.
The place is constructed by
`place_import_with_unique_ids_matches_main_96_store_bytes`: two service roots,
a folder, a part, a reference to the part and a ModuleScript, all with nonzero
UniqueId and HistoryId values. Both binary and XML input must produce these
same store bytes. These are Renium codec fixtures, not Studio memory layouts.
